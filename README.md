## 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/Milan07xt/Python-Develop-Intership-All-task.git
```

### 2. Open the project

```bash
cd Python-Develop-Intership-All-task
```

### 3. Check Python installation

```bash
python --version
```

or:

```bash
python3 --version
```

### 4. Run a Python program

For example:

```bash
python Syntax.py
```

To run a practice program:

```bash
python Practice/p1.py
```

You can similarly run Python files inside the `TASK` folders.
