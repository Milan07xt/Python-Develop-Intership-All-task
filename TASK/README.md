# Python Internship Tasks

This folder contains Python exercises organized by day. The folder names use two digits (`Day01`–`Day30`) so they appear in numeric order in file browsers and on GitHub.

## Day-by-day topics

| Day | Folder | Topics covered |
| ---: | --- | --- |
| 1 | `Day01` | Arithmetic, input, averages, marks, and escape characters |
| 2 | `Day02` | Conditions, operators, truthy/falsey values, and strings |
| 3 | `Day03` | String methods, character counts, and logical operators |
| 4 | `Day04` | Loops, `break`/`continue`, sums, and guessing exercises |
| 5 | `Day05` | Loops, even/odd checks, and maximum/minimum values |
| 6 | `Day06` | Functions, comparisons, multiplication tables, and even-number sums |
| 7 | `Day07` | Functions, default arguments, Fibonacci, lists, and palindrome checks |
| 8 | `Day08` | Lists, iteration, nested lists, and list-processing functions |
| 9 | `Day09` | Lists, tuples, tuple iteration, and built-in functions |
| 10 | `Day10` | Dictionaries, character counts, factorials, and divisors |
| 11 | `Day11` | Dictionaries, sets, and set operations |
| 12 | `Day12` | Sets, dictionaries, and list comprehensions |
| 13 | `Day13` | List, dictionary, and set comprehensions |
| 14 | `Day14` | Dictionary/set examples and functions using `*args` |
| 15 | `Day15` | `**kwargs`, positional arguments, and lambda functions |
| 16 | `Day16` | Variable-length arguments, keyword arguments, and lambda examples |
| 17–30 | `Day17`–`Day30` | Folders are ready for future exercises |

## Running an exercise

Each `.py` file is an individual exercise. From this folder, run a file with Python, for example:

```bash
python Day10/recursive_factorial.py
```

Use the filename shown in the selected day folder. Some exercises prompt for input; follow the prompts in the terminal.
